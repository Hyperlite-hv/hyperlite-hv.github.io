### Changed

- The interface is rebuilt as a console (#862): a header band with the search, the notifications and the account, a menu of services on the left with the ones you pin, and a Home page with the services, the resources opened recently, the state of the cluster and the running operations. Every service page opens with a breadcrumb, its title and a command bar; a machine, a container or a node opens on its own page, with its pages in a menu on its left. "All services" lists every service by family, "All resources" every machine, container and node in one list. The colours, the typeface (Inter) and the mark are new, and the theme follows the system setting unless you choose light or dark. Every page address and every `?tab=` link keeps working.

- Every page takes the console style (#862): plain tables with one line per row and links in the brand colour, thin frames, flat message bars and rectangular buttons; the commands above a page are flat. The page of a machine has a full command bar (Connect, Start, Restart, Stop, Back up, Migrate, Refresh, then More), and the page of a node one too (Create a VM, Shell, Maintenance mode, Refresh, More); an unavailable command stays visible and says why.
- The actions at the end of a row (Log, Shell, Stop, Details...) read as quiet links instead of a row of framed buttons; right click on a row still opens every action.

- The lists of nodes and containers follow the console too (#862): commands above the list (add or create, Refresh, Export to CSV), a filter on any field and filters read as sentences ("State equals", "Type equals"), a plain grid with a menu on every row. Lists that are a whole page are no longer framed.
- The filters of the Activity page read as sentences too ("Type", "Node", "Period"), next to its status buttons and its search.
- Storage, network and backups follow the same pattern: commands (create, Refresh, Export to CSV), a filter on any field, filters read as sentences (node, type, mode, state), the name first in the grid and a menu on every row.

- The pages of the virtual machines and the nodes follow the console (#862). The list of virtual machines has a command bar (Create, Manage view, Refresh, Export to CSV, then Start, Restart, Stop, Force stop, Delete and Migrate, which wait for a selection), filters read as sentences ("Node equals", "State equals", "Tag equals"), grouping by node by default with one head per node, and a "…" menu on every row. The overview of a machine, a node and a container opens with an "Essentials" block (with a JSON view); machines and nodes then have Properties, grouped by subject with a link to the page that changes each one, and Monitoring with their charts. Icons are drawn in one colour; the coloured tiles are gone.

- The list of virtual machines is calmer (#862): a flat list by default, one row with the filter, the state, the node and the tag, and everything about the layout (grouping, table or cards, columns, saved views) behind one "View" button. The detail of a machine opens when you choose its row instead of taking a third of the page from the start. Nothing is removed: grouping by node, tag or pool, the cards and the saved views are still there.
